# VisionFlow Automator

## 视觉识别自动脚本使用说明

VisionFlow Automator 通过识别屏幕或指定窗口中的 PNG 模板，自动执行鼠标点击、键盘输入、键盘移动和鼠标拖曳操作。它适合将重复的界面操作编排成可重复执行的任务流程。

> 注意：脚本会实际移动鼠标并发送键盘输入。第一次运行请关闭循环，只启用少量步骤测试。

## 1. 功能概览

- 识别 PNG 模板并点击界面元素。
- 按目标窗口区域识别，支持窗口不在前台时工作。
- 使用备用点击点和一个或多个识别区域提高稳定性。
- 高级步骤支持绑定多个候选模板，并按屏幕从左到右选择命中的模板。
- 等待画面变化、下一模板出现等结果条件。
- 使用 `custom`、`daily`、`side` 和用户创建的预设。
- 创建组和子组，启用/停用、排序、复制和批量删除任务。
- 使用 Ctrl/Shift 多选，按 Enter 批量启用或关闭步骤。
- 执行键盘移动、单次按键、鼠标拖曳和持续点击步骤。
- 循环执行完整任务队列，停止时可中断大多数等待和操作。

## 2. 安装与启动

### 2.1 环境

- Windows
- Python 3.9 或更高版本
- 目标程序允许模拟鼠标和键盘输入

在项目目录打开 PowerShell，安装依赖：

```powershell
python -m pip install numpy opencv-python mss pyautogui pygetwindow
```

如果安装了多个 Python，可使用：

```powershell
py -3 -m pip install numpy opencv-python mss pyautogui pygetwindow
```

### 2.2 启动

```powershell
cd "C:\Users\baconing\Desktop\脚本编辑器"
python gui.py
```

也可以双击 `启动脚本编辑器.vbs`。该文件通过 `pythonw gui.py` 启动，通常不会显示命令行窗口。VBS 无反应时，先运行 `python gui.py` 查看错误，并确认 `pythonw` 已加入 PATH。

## 3. 第一次运行

1. 打开目标程序，进入目标控件可见的页面。
2. 点击“刷新窗口”，在“目标窗口”下拉框选择目标程序。
3. 在“执行功能”中选择 `custom` 或目标预设。
4. 只启用一个已配置步骤，确认“循环执行”未勾选。
5. 点击“开始执行”。
6. 查看日志中的模板、置信度和点击坐标。
7. 确认无误后，再逐步启用其它步骤或整个组。

如果目标窗口列表为空，程序会使用当前活动窗口或屏幕区域。窗口移动、缩放或改变大小后，应重新检查点击点和识别区域。

## 4. 界面操作

### 4.1 顶部控制区

- **循环执行**：任务队列完成后从第一步重新执行。
- **执行功能**：切换 `custom`、内置预设和用户预设。
- **新建预设**：创建空白预设。
- **复制到预设**：把当前选中的组或步骤追加到其它预设。
- **删除预设**：删除当前预设及全部步骤；`custom` 不能删除。
- **目标窗口**：从刷新后的窗口列表中选择目标窗口。
- **刷新窗口**：重新读取当前可见窗口标题。
- **开始执行/停止**：启动或停止任务队列；停止会中断识别等待、延时、持续点击和拖曳。

### 4.2 项目列表

左侧列表显示当前预设的组和步骤，步骤前的勾选标记表示启用状态。

- 单击组或步骤：在右侧打开编辑内容。
- 双击步骤：切换启用状态。
- 按住 `Ctrl` 单击：选择多个不连续项目。
- 按住 `Shift` 单击：选择连续范围。
- 选中项目后按 `Enter`：批量切换启用状态。
- 选中组后按 `Enter`：切换该组及子组内步骤。
- **全选/清空**：启用/停用所有步骤。
- **上移/下移**：调整项目顺序。
- 拖动行右侧 `☰`：调整顺序或移动到其它组。
- 组颜色：在组设置中使用 HSV 颜色盘设置列表中的组背景色。
- **新增组/新增步骤**：创建组或任务。
- **复制**：复制当前列表中的选中项目。
- **删除**：批量删除所有选中步骤或组，删除组会同时删除组内步骤。

## 5. 模板图片

### 5.1 命名

程序启动时读取 `icons` 文件夹中的所有 PNG 图片。文件名去掉 `.png` 后就是任务中的模板名：

```text
icons/auto.png              -> auto
icons/start_loop.png        -> start_loop
icons/back_to_main_menu.png -> back_to_main_menu
```

模板名不需要扩展名。多个候选模板可用英文逗号或中文逗号分隔。

### 5.2 制作建议

1. 截取稳定、清晰且有辨识度的小区域。
2. 避免动态数字、倒计时和变化背景。
3. 截图时保持分辨率、窗口大小和系统缩放稳定。
4. 保存为 PNG 并放入 `icons` 文件夹。
5. 重新启动程序，或在步骤中重新绑定图片。

如果界面元素尺寸或布局变化明显，应为新环境重新制作模板。

## 6. 任务与预设

### 6.1 预设类型

- `custom`：自定义任务，保存于 `saved_tasks.json`。
- `daily`：内置每日任务预设。
- `side`：内置歧路任务预设。
- 用户预设：通过“新建预设”创建，保存于 `saved_presets.json`。

每个预设拥有独立的步骤、启用状态、组结构、组顺序和空组状态。切换预设时，程序会先保存当前预设，再加载目标预设。

### 6.2 创建预设

1. 点击“新建预设”。
2. 输入名称，不能使用 `custom`，也不能与现有名称重复。
3. 切换到新预设。
4. 点击“新增组”或“新增步骤”编排流程。
5. 修改步骤后点击“应用修改”。

### 6.3 复制到其它预设

1. 选择源预设，包括 `custom`。
2. 用 Ctrl/Shift 选中组或步骤。
3. 点击“复制到预设”。
4. 选择目标预设。
5. 点击“复制并切换”并确认追加。

选中组会复制该组及子组内的步骤；选中步骤只复制对应步骤。复制会追加内容，不会覆盖目标预设。

### 6.4 删除预设或组

- “删除预设”删除整个预设，删除状态会在重启后保留。
- “删除”删除选中的步骤或组。
- 删除组会同时删除组内和子组内的步骤。
- 删除空组不会自动恢复，组结构会随预设保存。

## 7. 编辑普通步骤

### 7.1 新建和保存

1. 选择目标预设和目标组。
2. 点击“新增步骤”，选择 `normal` 或 `advanced`。
3. 填写右侧表单。
4. 点击“应用修改”。

修改会自动保存到当前预设对应的 JSON 文件。

### 7.2 字段说明

- **模板名**：对应 `icons` 中的 PNG 文件名。
- **描述**：列表和日志中显示的名称。
- **X偏移/Y偏移**：在识别中心或备用点击点上增加偏移。
- **点击X/点击Y**：备用固定点击坐标。
- **左上/右下**：识别区域矩形坐标。
- **下一模板**：点击后等待出现的模板名。
- **框选出现位置**：限制“下一模板”出现结果的等待区域；该区域目前为单个矩形。
- **超时**：等待识别的最长时间，单位为秒；`0` 表示不限制。
- **等待方式**：画面变化、下一模板出现、画面变化后下一模板出现。
- **完成后等待**：进入下一步前额外等待的时间。
- **点击**：是否执行鼠标点击。
- **必须识别到图片再点击**：未识别到模板时不使用未知位置点击。
- **可选步骤（跳过）**：失败时继续后续步骤。
- **框选识别区域**：为当前步骤追加一段识别区域，可以重复添加多段区域。
- **清空识别区域**：删除当前步骤的全部识别区域，恢复全屏识别。

### 7.3 记录备用点击点

1. 选中步骤并点击“记录点击点”。
2. 编辑器窗口暂时隐藏。
3. 在目标程序中单击实际需要点击的位置。
4. 编辑器恢复后，坐标会写入“点击X”和“点击Y”。

### 7.4 框选识别区域

1. 选中步骤并点击“框选识别区域”。
2. 拖出第一段目标可能出现的矩形。
3. 松开鼠标后，再次点击“框选识别区域”并选择其它矩形。
4. 程序只在已添加的区域内识别，并合并各区域的匹配结果。
5. 点击“清空识别区域”可删除全部区域并恢复全屏识别。

按 `Esc` 可取消框选。窗口布局变化后应重新框选。

高级步骤可以绑定多个候选模板。执行时会同时识别这些模板，并选择最左侧的命中结果；同一横坐标附近优先选择置信度更高的模板。

## 8. 特殊步骤

### 8.1 `keyboard_move`：键盘移动

用于 3D 界面移动。按顺序添加按键和持续时间，例如 `W 1.0s`、`A 0.5s`，并可设置执行前延时和执行后等待。

### 8.2 `key_press`：单次按键

用于发送一次按键。可配置按键、执行前延时、按住时长和执行后等待，例如 `E` 或 `ESC`。

### 8.3 `drag`：鼠标拖曳

填写起点 X/Y、终点 X/Y 和拖动时长。坐标是屏幕坐标，不会自动适配窗口大小或分辨率。

### 8.4 `click_until_gone`：持续点击

按设定间隔点击记录的位置，直到识别到目标模板或画面发生变化。可以重复点击“绑定图片”添加多个候选模板，任一模板识别到即停止；也可以重复点击“框选识别区域”添加多个分段区域。点击间隔表示两次点击开始之间的目标时间；识别和点击本身耗时超过该值时，实际频率会受处理速度限制。可配置目标模板、点击间隔、超时时间、备用点击点、画面变化条件、`stop_delay` 和超时后是否继续下一步。绑定多个图片时也可以直接在输入框中使用英文逗号或中文逗号分隔。

### 8.5 迂回步骤

普通步骤和高级步骤都可以配置条件分支。迂回设置中可以分别指定“未识别时跳到”和“识别成功后跳到”的主流程步骤：识别成功后执行成功跳转，未识别时先执行迂回子步骤，再执行未识别跳转。留空表示继续下一步；原有 `detour_jump_to` 配置继续作为未识别跳转使用。高级步骤可使用多个候选模板，迂回子步骤不允许继续触发迂回，避免递归循环。

### 8.6 停止脚本

点击“停止”后，程序会通过停止信号中断识别轮询、步骤等待、按键持续时间、持续点击间隔、循环等待和拖曳过程。拖曳被中断时会释放鼠标左键。

## 9. 不同分辨率和缩放比例

### 9.1 配置差异

- **图片模板**：使用灰度模板匹配，并默认启用多尺度匹配，允许模板在 `0.8` 到 `1.2` 倍范围内变化。
- **固定点击点**：记录的是屏幕坐标，不会自动换算。
- **识别区域**：主识别区域支持多个分段矩形；“下一模板”出现位置仍为单个矩形。所有坐标与录制时相关，窗口布局变化后应重新框选。
- **拖曳步骤**：起点和终点是屏幕坐标，拖动时长控制整个拖曳过程，必须重新设置坐标。
- **键盘移动**：按键和时间可复用，但速度、帧率和视角变化可能影响结果。

### 9.2 1920×1080

工程内任务坐标按 1920×1080 环境记录。若分辨率、窗口位置、窗口大小和系统缩放一致，可以先直接测试，但仍需确认模板和点击位置。

### 9.3 1600×900、1366×768 等分辨率

1. 设置目标程序分辨率，固定窗口位置和大小。
2. 如果元素尺寸明显变化，重新截取 PNG 模板。
3. 对普通点击步骤重新记录点击点。
4. 重新框选识别区域。
5. 对拖曳步骤重新填写起点和终点。
6. 分段启用并测试，不要立即开启循环。

### 9.4 2K、4K 和 Windows 显示缩放

Windows 125%、150% 等缩放可能同时改变模板尺寸和坐标。建议固定窗口模式，重新截取模板、记录点击点和框选区域，再考虑调整匹配参数。不要只降低阈值解决分辨率问题，阈值过低会增加误识别。

### 9.5 目标窗口模式

选择目标窗口后，程序优先截取该窗口区域，即使窗口不在前台也可以识别。窗口移动、调整大小或切换 DPI 后，应重新检查模板、点击点、识别区域和拖曳坐标。

## 10. 文件与全局配置

### 10.1 文件结构

```text
脚本编辑器/
├─ gui.py                 图形界面入口
├─ main.py                任务执行和识别流程
├─ tasks.py               默认任务与保存逻辑
├─ config.py              全局识别、超时和窗口配置
├─ saved_tasks.json       custom 自定义任务
├─ saved_presets.json     用户预设、删除记录和分组信息
├─ icons/                 PNG 模板目录
├─ core/                  截屏、输入和模板匹配模块
└─ 启动脚本编辑器.vbs     使用 pythonw 启动界面
```

### 10.2 数据保存

`custom` 保存在 `saved_tasks.json`，其它预设保存在 `saved_presets.json`。修改前建议关闭程序并备份文件。手工修改时必须保持合法 JSON 格式。

### 10.3 `config.py` 常用参数

- `THRESHOLD`：模板匹配阈值，默认 `0.8`。
- `USE_MULTI_SCALE`：是否启用多尺度匹配。
- `SCALE_RANGE`：多尺度范围，默认 `(0.8, 1.2)`。
- `SCALE_STEP`：多尺度步长，默认 `0.05`。
- `MONITOR_INDEX`：监视器编号，`0` 表示全部，`1` 表示主屏。
- `DEFAULT_TIMEOUT`：默认等待超时时间。
- `DEFAULT_POLL_INTERVAL`：模板扫描间隔。
- `USE_WINDOW_MODE`：是否优先按目标窗口区域识别。

修改全局配置后请重新启动程序。

## 11. 常见问题

### 11.1 图片识别不到

检查模板是否在 `icons` 文件夹、模板名是否正确、目标窗口和页面是否正确、模板是否包含动态内容或被遮挡。然后重新截图或框选区域，最后再调整 `THRESHOLD`、`SCALE_RANGE` 或 `SCALE_STEP`。

### 11.2 点击位置不准确

重新使用“记录点击点”，或调整 X/Y 偏移。窗口移动、缩放或分辨率变化后，旧坐标可能失效。

### 11.3 操作了错误窗口

停止脚本，点击“刷新窗口”，重新从下拉框选择目标窗口。确认无误前不要开启循环。

### 11.4 启动时报缺少模块

重新安装依赖，并确认安装依赖和启动脚本使用的是同一个 Python：

```powershell
python -c "import numpy, cv2, mss, pyautogui, pygetwindow; print('依赖正常')"
```

### 11.5 预设或空组重新出现

修改预设后让程序正常保存，再切换或关闭程序。不要在程序运行时直接覆盖 JSON 文件，并检查 `saved_presets.json` 是否为合法 JSON。

### 11.6 步骤超时或脚本停止

确认目标页面、模板、等待方式和下一模板设置正确。适合容错的步骤可勾选“可选步骤（跳过）”；不适合无限等待的步骤应设置合理超时。

## 12. 安全建议

运行前确认：

- 目标程序已打开并停留在预期页面。
- 所有需要的 PNG 模板都在 `icons` 文件夹中。
- 已从“目标窗口”下拉框选择正确窗口。
- 第一次测试未勾选“循环执行”。
- 只启用了准备测试的步骤。
- 备用点击点和识别区域适用于当前窗口。
- 已确认脚本可能移动鼠标并发送键盘输入。

先分段测试，再启用完整流程。运行过程中不要将重要文件、设置界面或其它需要人工确认的窗口置于可能被误点击的位置，也不要在未验证配置的情况下长时间无人看管运行。
