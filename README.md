# 视觉识别自动脚本使用说明

## 1. 功能简介

本工具通过识别屏幕或指定窗口中的图片模板，自动执行点击、键盘按键、键盘移动和鼠标拖动等操作。适合把重复的界面操作编排成任务队列。

主要功能：

- 按图片模板识别界面元素并点击
- 支持指定目标窗口进行识别
- 支持备用点击坐标，避免模板偶尔识别不到时无法操作
- 支持框选识别区域，减少误识别并提升速度
- 支持等待画面变化、等待下一张模板出现等结果确认方式
- 支持每日、歧路预设，以及自定义任务
- 支持任务分组、启用/停用、排序、复制和循环执行
- 支持按键序列、单次按键、拖曳和持续点击直到目标出现等步骤

> 注意：脚本会实际移动鼠标并发送键盘输入。运行前请确认目标窗口和任务配置正确，并先用单步或短流程测试。

## 2. 运行环境

- Windows
- Python 3.9 或更高版本
- 目标程序允许使用模拟鼠标和键盘输入

首次运行前，在项目目录打开 PowerShell，安装依赖：

```powershell
python -m pip install numpy opencv-python mss pyautogui pygetwindow
```

如果电脑上同时安装了多个 Python，请使用实际运行脚本的 Python 命令替换 `python`，例如 `py -3`。

## 3. 启动程序

请先进入项目目录：

```powershell
cd "C:\Users\baconing\Desktop\脚本编辑器"
```

启动方式任选其一：

```powershell
python gui.py
```

也可以双击项目中的 `启动脚本编辑器.vbs`。该方式会调用 `pythonw`，通常不会显示命令行窗口。

如果双击 VBS 没有反应，请先确认命令行中执行 `python gui.py` 能正常打开界面，并确认 `pythonw` 已加入 PATH。

## 4. 准备图片模板

程序启动时会读取 `icons` 文件夹中的所有 PNG 图片。图片文件名（不含 `.png` 扩展名）就是任务中填写的模板名。

例如：

```text
icons/auto.png              -> 模板名填写 auto
icons/start_loop.png        -> 模板名填写 start_loop
icons/back_to_main_menu.png -> 模板名填写 back_to_main_menu
```

制作模板时建议：

1. 截取目标程序中稳定、清晰且具有辨识度的小区域。
2. 尽量不要包含动态数字、倒计时或不断变化的背景。
3. 截图时保持目标程序的分辨率、缩放比例和显示状态一致。
4. 将图片保存为 PNG，并放入 `icons` 文件夹。
5. 添加或替换模板后，重新启动程序，或在界面中重新绑定图片以刷新模板。

模板名区分大小写时应以实际文件名为准；多个候选模板可以用英文逗号或中文逗号分隔。

## 5. 第一次使用流程

### 5.1 选择目标窗口

1. 打开需要自动操作的目标程序，并让目标界面处于可识别状态。
2. 点击“刷新窗口”，然后在“目标窗口”下拉框中选择窗口。
3. 如果列表为空，程序会使用当前活动窗口或屏幕区域。

指定窗口后，识别会优先使用该窗口区域。窗口移动或改变大小后，建议重新检查记录的点击点和识别区域。

### 5.2 选择执行功能

“执行功能”有三种模式：

- `custom`：执行 `saved_tasks.json` 中保存的自定义任务，仅执行已启用步骤。
- `daily`：执行内置的每日任务预设。
- `side`：执行内置的歧路任务预设。

点击“新建预设”可以创建一个空白预设。输入名称后，新预设会出现在下拉框中；切换到它后可通过“新增步骤”编排流程。预设会保存到项目根目录的 `saved_presets.json`，与 `custom` 的 `saved_tasks.json` 分开保存。`custom` 也属于可复制的预设，可以作为复制来源或目标。切换“执行功能”时，直接点击列表中的步骤即可编辑当前预设，不会跳回自定义任务。按住 `Ctrl` 可以选择多个不连续的组或步骤，按住 `Shift` 可以选择连续范围；选择完成后点击“复制到预设”，再指定目标预设，即可把选中的组或步骤追加过去，不会覆盖目标预设。点击“删除”可以一次删除所有选中的步骤或组；删除组时会同时删除组内步骤。点击“删除预设”可以删除当前预设，删除操作需要确认。

选中一个或多个步骤后按 `Enter`，可以批量启用或关闭步骤；选中组后按 `Enter`，会同步切换该组及子组中的步骤状态。

选择 `custom` 后，左侧“项目列表”中的勾选状态决定是否执行该步骤。双击步骤可以启用或停用；组也可以整体启用或停用。

### 5.3 开始和停止

- 点击“开始执行”启动任务队列。
- 勾选“循环执行”后，队列完成会从头再次执行。
- 点击“停止”请求停止。正在进行的当前动作结束后，脚本会退出。
- “日志输出”区域会显示当前步骤、模板识别结果、点击位置和错误信息。

## 6. 编辑自定义步骤

在 `custom` 模式下，常用操作如下：

- “新增步骤”：添加普通识别/点击步骤。
- “绑定图片”：从 `icons` 文件夹选择模板，填写的名称不含 `.png`。
- “记录点击点”：隐藏脚本界面后，在目标位置单击，记录备用坐标。适合目标图片不稳定或需要点击图片中心以外位置的情况。
- “框选识别区域”：拖出一个矩形，仅在该区域查找当前模板。
- “应用修改”：保存当前步骤的模板、描述、坐标、等待方式等设置。
- “上移”“下移”：调整执行顺序。
- “复制”“删除”：复制或删除当前步骤。
- “新增组”：建立任务分组；选中一个组后新增，可建立子组。

普通步骤的主要字段：

- **模板名**：对应 `icons` 中的 PNG 文件名；多个候选模板用逗号分隔。
- **描述**：日志和列表中显示的名称。
- **X偏移 / Y偏移**：在识别中心或备用点击点基础上增加的点击偏移量。
- **点击X / 点击Y**：固定备用点击坐标。优先使用“记录点击点”生成的坐标。
- **下一模板**：点击后等待出现的模板名。
- **超时**：等待识别的最长时间，单位为秒；填写 `0` 表示不限制。
- **等待方式**：选择画面结果变化、等待目标模板出现，或等待画面变化后目标结果出现。
- **完成后等待**：当前步骤完成后，开始下一步前额外等待的时间。
- **点击**：是否执行鼠标点击。
- **必须识别到图片再点击**：避免模板未识别时直接点击未知位置。
- **可选步骤（跳过）**：步骤失败时允许继续后续步骤。

设置完成后点击“应用修改”。程序会自动写入 `saved_tasks.json`。

## 7. 特殊步骤

部分步骤会显示专用编辑界面：

- **每日移动步骤**：添加按键（如 `W`、`A`、`S`、`D`）及持续时间，按列表顺序发送按键。
- **按键步骤**：设置按键、执行前延时、按住时长和执行后等待。
- **拖曳步骤**：填写起点 X/Y、终点 X/Y 和拖动时长。坐标为屏幕坐标。
- **持续点击直到识别步骤**：绑定目标模板并记录点击点；脚本会按设定间隔点击，直到识别到目标，或达到超时。

持续点击步骤也可以勾选“画面发生变化后视为识别成功”。如果希望识别成功后继续点击一段时间，请设置该步骤的停止延时（`stop_delay`）。

## 8. 文件说明

```text
脚本编辑器/
├─ gui.py                 图形界面入口
├─ main.py                任务执行和识别流程
├─ tasks.py               默认任务与任务保存逻辑
├─ config.py              全局识别、超时和窗口配置
├─ saved_tasks.json       自定义任务数据，程序会自动更新
├─ saved_presets.json     自定义预设数据，创建或修改预设后自动生成
├─ icons/                 PNG 模板图片目录
├─ core/                  截屏、输入和模板匹配模块
└─ 启动脚本编辑器.vbs     使用 pythonw 启动图形界面
```

修改 `saved_tasks.json` 前建议先关闭程序并备份文件。手工修改时应保持合法 JSON 格式；如果文件损坏或为空，程序可能回退到默认任务。

常用配置位于 `config.py`：

- `THRESHOLD`：模板匹配阈值，默认 `0.75`。识别不到可适当降低，误识别多则提高。
- `USE_MULTI_SCALE`：是否启用多尺度匹配。
- `SCALE_RANGE`、`SCALE_STEP`：多尺度匹配范围和步长。
- `MONITOR_INDEX`：截屏监视器编号，`0` 表示全部，`1` 表示主屏。
- `DEFAULT_TIMEOUT`：默认等待超时时间。
- `DEFAULT_POLL_INTERVAL`：扫描间隔。

调整全局配置后请重新启动程序。

## 9. 常见问题

### 图片识别不到

检查模板是否放在 `icons` 文件夹、模板名是否正确、目标窗口是否选择正确。然后检查目标程序的缩放比例、窗口大小和模板截图是否一致。也可以重新截图，并使用“框选识别区域”缩小搜索范围。

### 点击位置不准确

使用“记录点击点”设置备用坐标，或调整 X/Y 偏移。若目标窗口移动或缩放，记录的坐标可能需要重新采集。

### 运行后操作了错误窗口

停止脚本，在“目标窗口”中重新选择目标窗口。不要在未确认窗口标题时直接开启循环执行。

### 脚本启动时报缺少模块

重新执行依赖安装命令。若仍失败，确认安装依赖和启动脚本使用的是同一个 Python：

```powershell
python -c "import numpy, cv2, mss, pyautogui, pygetwindow; print('依赖正常')"
```

### 日志显示超时或脚本异常停止

确认目标界面已经打开并处于预期页面；提高步骤超时时间，检查等待方式和下一模板设置。对于允许失败的步骤，可勾选“可选步骤（跳过）”。

## 10. 安全使用建议

首次配置时关闭“循环执行”，只启用一个步骤进行测试。确认识别和点击位置正确后，再逐步启用后续步骤。运行过程中不要把鼠标移动到可能触发其他重要操作的位置，也不要在未验证任务配置的情况下长时间无人看管运行。

## 11. 完整操作示例

下面以“创建一个识别按钮并点击，然后等待下一界面出现”为例说明完整流程。

### 11.1 准备目标界面

1. 打开目标程序，进入包含要点击按钮的页面。
2. 确认目标按钮在屏幕上清晰可见，并且不会被弹窗、鼠标指针或其它窗口遮挡。
3. 使用截图工具截取按钮本身或按钮中稳定的图标区域。
4. 将截图保存为 PNG，例如 `confirm.png`，放入 `icons` 文件夹。

### 11.2 创建任务

1. 启动脚本编辑器。
2. 在“执行功能”中选择 `custom`，或者点击“新建预设”创建一个专用预设。
3. 点击“新增组”，为流程创建一个分组，例如“测试流程”。
4. 选中该组，点击“新增步骤”，选择 `normal`。
5. 在“模板名”中填写 `confirm`，或点击“绑定图片”选择 `confirm.png`。
6. 填写步骤描述，例如“点击确认按钮”。
7. 保持“点击”和“必须识别到图片再点击”勾选。
8. 设置超时时间，例如 `10` 秒。
9. 如果点击后会出现下一界面，在“下一模板”中填写下一个 PNG 的文件名。
10. 将等待方式设置为“等待目标模板出现”。
11. 点击“应用修改”。

保存后，步骤会出现在左侧列表中，并写入当前任务文件。此时建议关闭循环，只测试这一个步骤。

### 11.3 测试任务

1. 在“目标窗口”下拉框中点击“刷新窗口”，选择目标程序窗口。
2. 确认左侧步骤前的勾选标记处于启用状态。
3. 确认目标程序停留在模板可见的页面。
4. 点击“开始执行”。
5. 观察“日志输出”，确认识别到的模板、置信度和点击坐标正确。
6. 如果识别或点击不正确，点击“停止”，调整模板、识别区域、备用点击点或偏移量后重新测试。

## 12. 界面操作速查

### 顶部控制区

- **循环执行**：任务队列完成后重新从第一步开始。
- **执行功能**：选择 `custom`、内置预设或用户创建的预设。
- **新建预设**：创建空白预设。
- **复制到预设**：把当前预设中选中的组或步骤追加到其它预设。
- **删除预设**：删除当前预设及其全部步骤。`custom` 是固定的自定义预设，不能删除。
- **目标窗口**：只能从刷新后的窗口列表中选择目标窗口。
- **刷新窗口**：重新读取当前可见窗口标题。

### 项目列表操作

- 单击一个组或步骤：在右侧打开编辑内容。
- 按住 `Ctrl` 再单击：增加或取消一个不连续的选项。
- 按住 `Shift` 再单击：选择连续范围。
- 双击步骤：切换该步骤的启用状态。
- 选中一个或多个步骤后按 `Enter`：批量切换启用状态。
- 选中组后按 `Enter`：切换该组及子组内所有步骤。
- 点击“删除”：一次删除所有选中的步骤或组；删除组会同时删除组内步骤。
- 点击“复制”：复制当前选中的单个步骤或组到当前列表。
- 点击“复制到预设”：将当前选中的多个组/步骤追加到另一个预设，不会覆盖目标预设。
- 点击“上移”或“下移”：移动选中的项目。也可以拖动列表行右侧的 `☰` 手柄调整顺序或分组。
- 点击“全选”：启用所有步骤；点击“清空”：停用所有步骤。

### 记录点击点与识别区域

“记录点击点”适用于模板识别不稳定，或实际应该点击图标旁边的固定位置的情况：

1. 选中步骤并点击“记录点击点”。
2. 脚本编辑器窗口会暂时隐藏。
3. 在目标程序中单击需要点击的位置。
4. 编辑器恢复后，坐标会写入“点击X”和“点击Y”。

“框选识别区域”适用于画面中有多个相似元素的情况：

1. 选中步骤并点击“框选识别区域”。
2. 在屏幕上拖出目标可能出现的矩形范围。
3. 松开鼠标后，区域坐标会自动填入表单。
4. 程序优先在该区域识别，未找到时会逐步扩大搜索范围。

按 `Esc` 可以取消正在进行的区域框选。

## 13. 预设和数据保存规则

项目中有两类任务数据：

- `custom`：保存在 `saved_tasks.json`，用于自定义任务。
- 其它预设：保存在 `saved_presets.json`，包括内置预设被修改后的内容、用户创建的预设、预设删除记录和分组信息。

切换预设时，程序会先保存当前预设，再加载目标预设。每个预设的步骤、启用状态、组结构和空组状态相互独立。

### 复制组或步骤到其它预设

1. 在顶部选择源预设。
2. 在左侧用 Ctrl 或 Shift 选中一个或多个组/步骤。
3. 点击“复制到预设”。
4. 在弹窗中选择目标预设。
5. 点击“复制并切换”，确认追加。

选中组时会复制该组及子组中的步骤；选中单个步骤时只复制该步骤。复制不会清空目标预设原有流程。

### 删除预设和删除组的区别

- “删除预设”删除整个预设，并且删除状态会在重启后保留。
- “删除”删除当前预设中的选中组或步骤。
- 删除空组后不会自动恢复；组名、顺序和父子关系会随当前预设保存。
- 如果删除了内置 `daily` 或 `side`，它们不会在重启后重新出现。重新创建同名预设后，该名称可以再次使用。

建议在批量编辑前备份 `saved_tasks.json` 和 `saved_presets.json`。这两个文件都是 JSON 文本，可以复制到其它位置作为备份。

## 14. 任务类型选择建议

根据操作目标选择步骤类型：

| 目标 | 推荐类型 | 需要配置的内容 |
| --- | --- | --- |
| 找到图片并点击 | `normal` | 模板名、超时、点击和等待方式 |
| 同一位置可能出现不同图片 | `advanced` | 多个候选模板名，用逗号分隔 |
| 在 3D 界面移动 | `keyboard_move` | 按键序列和每个按键持续时间 |
| 发送一次按键 | `key_press` | 按键、按住时长、前后延时 |
| 拖动滑块或列表 | `drag` | 起点、终点和拖动时长 |
| 重复点击直到状态出现 | `click_until_gone` | 模板、点击点、点击间隔和超时 |

普通步骤适合有稳定图片的按钮。若按钮点击后图片会消失，可以使用等待画面结果变化；若下一页面有稳定图片，优先设置“下一模板”和“等待目标模板出现”。

## 15. 识别参数调节顺序

识别失败时建议按以下顺序处理：

1. 检查模板名是否与 PNG 文件名一致。
2. 重新截图，去掉动态文字和变化背景。
3. 确认目标窗口、分辨率和系统显示缩放没有变化。
4. 使用“框选识别区域”缩小搜索范围。
5. 确认模板尺寸没有过大，且目标界面没有被遮挡。
6. 最后再调整 `config.py` 中的 `THRESHOLD`。

不要一开始就大幅降低匹配阈值。阈值过低可能让脚本把相似但错误的图片当成目标。
