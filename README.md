# 视觉识别自动脚本使用说明

本项目通过识别屏幕或指定窗口中的图片模板，自动执行鼠标点击、键盘按键、键盘移动和鼠标拖曳操作。它适合把重复的界面操作编排成可重复执行的任务流程。

> 注意：脚本会实际移动鼠标并发送键盘输入。第一次运行时请关闭循环，只启用少量步骤进行测试。

## 1. 功能概览

项目支持以下能力：

- 通过 PNG 模板识别界面元素并点击
- 按目标窗口区域进行识别，支持窗口不在前台时工作
- 使用备用点击坐标处理图片识别不稳定的情况
- 框选识别区域，减少误识别并提升扫描速度
- 等待画面变化、等待下一张模板出现，或等待画面变化后模板出现
- 使用 `custom` 自定义任务，以及 `daily`、`side` 和用户创建的预设
- 创建组、子组，启用/停用、排序、复制和批量删除任务
- 使用 Ctrl/Shift 多选步骤或组
- 按 Enter 批量启用或关闭选中的步骤
- 执行键盘移动、单次按键、鼠标拖曳和持续点击步骤
- 通过循环执行重复运行完整任务队列

## 2. 安装与启动

### 2.1 运行环境

- Windows
- Python 3.9 或更高版本
- 目标程序允许使用模拟鼠标和键盘输入

在项目目录打开 PowerShell，安装依赖：

```powershell
python -m pip install numpy opencv-python mss pyautogui pygetwindow
```

如果电脑安装了多个 Python，可以使用实际解释器对应的命令，例如：

```powershell
py -3 -m pip install numpy opencv-python mss pyautogui pygetwindow
```

### 2.2 进入项目目录

```powershell
cd "C:\Users\baconing\Desktop\脚本编辑器"
```

路径应替换为项目实际所在目录。

### 2.3 启动方式

命令行启动：

```powershell
python gui.py
```

也可以双击项目中的 `启动脚本编辑器.vbs`。该文件使用 `pythonw gui.py` 启动，通常不会显示命令行窗口。

如果双击 VBS 没有反应，先在 PowerShell 中运行 `python gui.py` 检查错误，并确认 `pythonw` 已加入 PATH。

## 3. 第一次运行

按下面顺序完成一次最小测试：

1. 打开目标程序，并进入目标控件可见的页面。
2. 点击“刷新窗口”，在“目标窗口”下拉框中选择目标程序。
3. 在“执行功能”中选择 `custom`。
4. 在左侧只启用一个已经配置好的步骤。
5. 确认“循环执行”未勾选。
6. 点击“开始执行”。
7. 查看底部日志，确认模板、置信度和点击坐标正确。
8. 测试无误后，再逐步启用其它步骤或整个组。

如果“目标窗口”列表为空，程序会使用当前活动窗口或屏幕区域。窗口移动、缩放或改变大小后，应重新检查点击点和识别区域。

## 4. 界面结构

### 4.1 顶部控制区

- **循环执行**：任务队列完成后从第一步重新执行。
- **执行功能**：切换 `custom`、内置预设和用户创建的预设。
- **新建预设**：创建空白预设。
- **复制到预设**：把当前选中的组或步骤追加到其它预设。
- **删除预设**：删除当前预设及其全部步骤；`custom` 不能删除。
- **目标窗口**：从刷新后的窗口列表中选择目标窗口。
- **刷新窗口**：重新读取当前可见窗口标题。

### 4.2 项目列表

左侧列表显示当前预设的组和步骤。步骤前的勾选标记表示启用状态。

- 单击组或步骤：在右侧打开编辑内容。
- 双击步骤：切换该步骤的启用状态。
- 按住 `Ctrl` 单击：选择多个不连续项目。
- 按住 `Shift` 单击：选择连续范围。
- 选中项目后按 `Enter`：批量切换启用状态。
- 选中组后按 `Enter`：切换该组及子组内步骤。
- **全选**：启用所有步骤。
- **清空**：停用所有步骤。
- **上移/下移**：调整选中项目顺序。
- 拖动行右侧的 `☰`：调整步骤顺序或将步骤移动到其它组。
- **新增组**：创建组；选中一个组后新增可以创建子组。
- **新增步骤**：创建新步骤。
- **复制**：在当前预设中复制选中的单个步骤或组。
- **删除**：批量删除所有选中的步骤或组。

### 4.3 日志输出

日志区域显示任务启动、当前步骤、模板识别结果、置信度、点击坐标、等待状态和错误信息。出现超时或误操作时，应先点击“停止”，再根据日志定位步骤。

## 5. 模板图片

### 5.1 命名规则

程序启动时读取 `icons` 文件夹中的所有 PNG 图片。文件名去掉 `.png` 后就是任务中填写的模板名：

```text
icons/auto.png              -> auto
icons/start_loop.png        -> start_loop
icons/back_to_main_menu.png -> back_to_main_menu
```

模板名应与文件名一致，不需要填写扩展名。多个候选模板可以使用英文逗号或中文逗号分隔。

### 5.2 制作模板

1. 截取稳定、清晰且有辨识度的小区域。
2. 尽量不要包含动态数字、倒计时或变化的背景。
3. 截图时保持目标程序的分辨率、窗口大小和系统缩放稳定。
4. 保存为 PNG 并放入 `icons` 文件夹。
5. 重新启动程序，或在步骤中重新绑定图片。

如果按钮尺寸、颜色或界面布局在不同环境中变化明显，应为该环境重新制作模板。

## 6. 任务与预设

### 6.1 预设类型

- `custom`：自定义任务，保存于 `saved_tasks.json`。
- `daily`：内置每日任务预设。
- `side`：内置歧路任务预设。
- 用户预设：点击“新建预设”创建，保存于 `saved_presets.json`。

每个预设拥有独立的步骤、启用状态、组结构、组顺序和空组状态。切换预设时，程序会先保存当前预设，再加载目标预设。

### 6.2 创建预设

1. 点击“新建预设”。
2. 输入预设名称，不能使用 `custom`，且不能与现有名称重复。
3. 切换到新预设。
4. 点击“新增组”或“新增步骤”编排流程。
5. 修改步骤后点击“应用修改”。

### 6.3 复制组或步骤到其它预设

1. 在顶部选择源预设，包括 `custom`。
2. 在左侧使用 Ctrl/Shift 选中组或步骤。
3. 点击“复制到预设”。
4. 选择目标预设。
5. 点击“复制并切换”，确认追加。

选中组时会复制该组及子组中的步骤；选中步骤时只复制对应步骤。复制内容会追加到目标预设，不会覆盖目标预设原有流程。复制的组会使用独立 ID，避免不同预设互相影响。

### 6.4 删除预设或组

- 点击“删除预设”：删除整个预设，删除状态会在重启后保留。
- 点击“删除”：删除当前选中的步骤或组。
- 删除组：同时删除组内及子组内的步骤。
- 删除空组：不会自动恢复，组结构会随预设保存。

如果删除了内置 `daily` 或 `side`，它们不会在重启后重新出现。重新创建同名预设后，该名称可以再次使用。

## 7. 编辑普通步骤

### 7.1 新建和保存

1. 选择目标预设和目标组。
2. 点击“新增步骤”，选择 `normal` 或 `advanced`。
3. 填写右侧表单。
4. 点击“应用修改”。

修改会自动保存到当前预设对应的 JSON 文件。

### 7.2 普通步骤字段

- **模板名**：对应 `icons` 中的 PNG 文件名。
- **描述**：列表和日志中显示的名称。
- **X偏移/Y偏移**：在识别中心或备用点击点上增加偏移。
- **点击X/点击Y**：备用固定点击坐标。
- **左上/右下**：识别区域矩形坐标。
- **中心**：识别区域中心，通常由矩形自动计算。
- **下一模板**：点击后等待出现的模板名。
- **超时**：等待识别的最长时间，单位为秒；`0` 表示不限制。
- **等待方式**：画面结果变化、等待目标模板出现、画面变化后目标结果出现。
- **完成后等待**：当前步骤完成后，进入下一步前额外等待的时间。
- **点击**：是否执行点击。
- **必须识别到图片再点击**：模板未识别时不使用未知位置点击。
- **可选步骤（跳过）**：步骤失败时继续后续步骤。

### 7.3 记录备用点击点

适用于图片不稳定，或需要点击模板中心以外位置的情况：

1. 选中步骤，点击“记录点击点”。
2. 编辑器窗口会暂时隐藏。
3. 在目标程序中单击实际需要点击的位置。
4. 编辑器恢复后，坐标会写入“点击X”和“点击Y”。

### 7.4 框选识别区域

适用于画面中存在多个相似元素的情况：

1. 选中步骤，点击“框选识别区域”。
2. 在屏幕上拖出目标可能出现的矩形范围。
3. 松开鼠标，区域坐标会自动填入表单。
4. 程序优先在该区域识别，未命中时会逐步扩大搜索范围。

按 `Esc` 可以取消区域框选。窗口移动或布局变化后应重新框选。

## 8. 特殊步骤

### 8.1 `keyboard_move`：键盘移动

用于 3D 界面移动。按列表顺序添加按键和持续时间，例如 `W 1.0s`、`A 0.5s`。可设置执行前延时和执行后等待。

键盘移动使用按键和时间，不依赖鼠标坐标，但不同帧率、速度或视角仍可能造成最终位置变化，需要重新测试。

### 8.2 `key_press`：单次按键

用于发送一次按键。可配置按键、执行前延时、按住时长和执行后等待，例如按住 `E` 或发送 `ESC`。

### 8.3 `drag`：鼠标拖曳

填写起点 X/Y、终点 X/Y 和拖动时长。坐标是屏幕坐标，不会自动适配窗口大小或分辨率。

### 8.4 `click_until_gone`：持续点击

脚本会按设定间隔点击记录的位置，直到识别到目标模板或画面发生变化。

需要配置：

- 目标模板
- 点击间隔
- 超时时间
- 备用点击点
- 是否以画面变化作为成功条件
- `stop_delay`：识别成功后继续点击的时间
- 是否在超时后继续下一步骤

## 10. 不同分辨率和缩放比例

### 10.1 配置类型的差异

- **图片模板**：默认启用多尺度匹配，允许模板在 `0.8` 到 `1.2` 倍范围内变化。分辨率相近时可能仍然有效。
- **固定点击点**：`点击X/点击Y` 和记录点击点是坐标值，不会自动换算。
- **识别区域**：框选矩形与录制时坐标相关，窗口布局变化后应重新框选。
- **拖曳步骤**：起点和终点是屏幕坐标，必须重新设置。
- **键盘移动**：按键和时间可以复用，但速度、帧率和视角变化可能影响结果。

### 10.2 1920×1080

示例流程按 1920×1080 记录。如果分辨率、窗口位置、窗口大小和系统缩放都一致，可以先直接测试，但仍需确认模板和点击位置。

### 10.3 1600×900、1366×768 等分辨率

1. 设置目标程序的新分辨率，并固定窗口位置和大小。
2. 如果界面元素尺寸明显变化，重新截取 PNG 模板。
3. 对普通点击步骤重新使用“记录点击点”。
4. 重新使用“框选识别区域”。
5. 对拖曳步骤重新填写起点和终点。
6. 分段启用并测试，不要立即开启循环。

### 10.4 2K、4K 和 Windows 显示缩放

Windows 125%、150% 等显示缩放可能同时改变模板尺寸和坐标。建议固定窗口模式，重新截取模板、记录点击点和框选区域，再考虑调整匹配参数。

不要只通过降低阈值解决分辨率问题，阈值过低会增加误识别和误点击。

### 10.5 目标窗口模式

选择目标窗口后，程序优先截取该窗口区域，即使窗口不在前台也可以识别。窗口移动、调整大小或切换 DPI 后，应重新检查模板、点击点、识别区域和拖曳坐标。

最稳定的做法是固定目标窗口的分辨率、大小、位置和系统缩放，并在相同环境下制作模板和运行脚本。

## 11. 文件与全局配置

### 11.1 文件结构

```text
脚本编辑器/
├─ gui.py                 图形界面入口
├─ main.py                任务执行和识别流程
├─ tasks.py               默认任务与任务保存逻辑
├─ config.py              全局识别、超时和窗口配置
├─ saved_tasks.json       custom 自定义任务
├─ saved_presets.json     用户预设、删除记录和分组信息
├─ icons/                 PNG 模板图片目录
├─ core/                  截屏、输入和模板匹配模块
└─ 启动脚本编辑器.vbs     使用 pythonw 启动界面
```

### 11.2 任务数据

`custom` 保存于 `saved_tasks.json`，其它预设保存于 `saved_presets.json`。建议修改前关闭程序并备份这两个文件。手工修改时必须保持合法 JSON 格式；文件损坏或为空时，程序可能回退到默认任务。

### 11.3 `config.py` 常用参数

- `THRESHOLD`：模板匹配阈值，默认 `0.75`。识别不到可适当降低，误识别多则提高。
- `USE_COLOR_MATCHING`：是否使用彩色模板匹配。
- `USE_MULTI_SCALE`：是否启用多尺度匹配。
- `SCALE_RANGE`：多尺度范围，默认 `(0.8, 1.2)`。
- `SCALE_STEP`：多尺度步长，默认 `0.05`。
- `MONITOR_INDEX`：监视器编号，`0` 表示全部，`1` 表示主屏。
- `DEFAULT_TIMEOUT`：默认等待超时时间。
- `DEFAULT_POLL_INTERVAL`：模板扫描间隔。
- `USE_WINDOW_MODE`：是否优先按目标窗口区域识别。

调整全局配置后请重新启动程序。

## 12. 常见问题

### 12.1 图片识别不到

按以下顺序检查：

1. 模板是否位于 `icons` 文件夹。
2. 模板名是否与 PNG 文件名一致。
3. 目标窗口和目标页面是否正确。
4. 模板是否包含动态内容或被其它窗口遮挡。
5. 是否需要重新框选识别区域。
6. 分辨率、窗口大小和系统缩放是否与制作模板时一致。
7. 最后再调整 `THRESHOLD`、`SCALE_RANGE` 或 `SCALE_STEP`。

### 12.2 点击位置不准确

重新使用“记录点击点”，或调整 X/Y 偏移。窗口移动、缩放或分辨率变化后，旧坐标可能已经失效。

### 12.3 操作了错误窗口

停止脚本，点击“刷新窗口”，重新从下拉框选择目标窗口。确认无误前不要开启循环执行。

### 12.4 启动时报缺少模块

重新安装依赖，并确认安装依赖和启动脚本使用的是同一个 Python：

```powershell
python -c "import numpy, cv2, mss, pyautogui, pygetwindow; print('依赖正常')"
```

### 12.5 预设或空组重新出现

修改预设后应让程序正常保存，再切换或关闭程序。不要在程序运行时直接手工覆盖 JSON 文件。建议关闭程序后备份并检查 `saved_presets.json` 是否是合法 JSON。

### 12.6 步骤超时或脚本停止

确认目标页面、模板、等待方式和下一模板设置正确。适合容错的步骤可以勾选“可选步骤（跳过）”；不适合无限等待的步骤应设置合理超时。

## 13. 安全建议

运行前确认：

- 目标程序已打开并停留在预期页面。
- 所有需要的 PNG 模板都在 `icons` 文件夹中。
- 已从“目标窗口”下拉框选择正确窗口。
- 第一次测试未勾选“循环执行”。
- 只启用了准备测试的步骤。
- 备用点击点和识别区域仍适用于当前窗口。
- 已确认脚本可能移动鼠标并发送键盘输入。

先分段测试，再启用完整流程。运行过程中不要将重要文件、设置界面或其它需要人工确认的窗口置于可能被误点击的位置，也不要在未验证配置的情况下长时间无人看管运行。
